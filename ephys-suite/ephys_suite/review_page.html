Cells

Pick a cell on the left to start.
  • The event the computer found sits on the dashed line. Inward events point down.
  • Detected = the computer thinks it is an event. Maybe = the computer is unsure. Judge both the same way.
  • A real event: fast drop, then a slower smooth return to baseline. A single sharp spike or a wobble the size of the noise is not an event.
