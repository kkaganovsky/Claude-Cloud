How to use Organoid Sizer

    

      

        
Workflow

        
    
          
  1. Open folder (top bar) or drag images in.
    2. 
          
  2. Scale tab: microscope files are calibrated from their metadata automatically. Otherwise type the pixel size, or draw a line on the ruler / scale bar and type its length. “Apply to all images” for a batch from the same scanner.
    3. 
          
  3. Detect tab: Detect in this image. If organoids are missed or split, set the expected diameter and try again.
    4. 
          
  4. Fix: click an organoid and press Del (wrong), X (exclude, e.g. touching / fused), 2 (split a fused pair). Add missed ones with the circle C or outline P tool.
    5. 
          
  5. Tick Reviewed, go to the next image (PgDn).
    6. 
          
  6. Export all: one CSV per image + summaries.
    7. 
        

        
Excluded vs. deleted

        
Delete removes a false detection. Exclude keeps the organoid in the CSV with status “excluded” and the reason (touching, fused, out of focus…), but leaves it out of the summaries – so the decision is documented.
