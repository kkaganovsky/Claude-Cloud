## What the app does with these

- **Switch journal…** restyles the whole project (artboard width, artwork scale, letter style, naming, text-size range, grid).
- **Check rules** lists widths, heights, text sizes, line weights, letter style, overlaps and panels outside the artboard.
- Values you edit are stored in the file (`settings.journalOverrides`) and travel with it.
